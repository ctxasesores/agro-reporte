## Despues de subir

1. Esperar que GitHub Pages termine el deploy.
2. Abrir `https://ctxasesores.github.io/agro-reporte/` en una ventana privada.
3. Probar login, recuperacion de contrasena, Ganaderia estandar, Ganaderia PRO, Tambo y panel BCRA.
4. Si el navegador muestra una version vieja, hacer recarga fuerte o borrar datos del sitio.
